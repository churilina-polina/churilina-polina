## Как устроены мои проекты

- Работа разбита на этапы, на каждом есть проверяемый результат.
- Есть автотесты и CI, чтобы изменения не ломали готовое.
- У каждого проекта есть README с описанием, стеком и инструкцией запуска, у API есть Swagger-документация.
